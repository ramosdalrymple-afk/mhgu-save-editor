## MHGU Save Editor by Dalrymple — Early Access

A redesigned desktop workspace inspired by Monster Hunter Generations Ultimate:
dark steel surfaces, gold accents, an original crest, and clearer navigation.

### What's new

- Redesigned navigation, hunter statistics, profile layout, and opening screen.
- Separate inventory **Edit slot** and **Add item** panels, with pinned actions.
- Refined equipment inspectors, list selection, spacing, and typography.
- Collection cards for materials, Guild Card awards, and Hunter Arts.
- Crest branding for the app, taskbar, shortcuts, and Windows installer.
- **by Dalrymple** credit in the application title.
- **Ctrl+O** to open a save; **Ctrl+S** to save changes.

Windows x64 only. Both packages include the .NET runtime. The application and
installer are unsigned. Original game artwork, extracted sprites, saves, keys,
and game archives are excluded from public packages.

### Early-access guidance

Work with a copy of your save folder and close the game or emulator before saving.
Timestamped backups are created before existing save files are replaced.

The equipment limitations from the previous prerelease remain:

- Palico gear creation targets the hunter box rather than the separate Palico box.
- Clearing worn or registered gear does not update equipped/My Set references.
- Non-talisman jewel capacity is not checked against the actual piece's sockets.
- Talisman rarity and charm origin are not synchronized automatically.

Read the [known limitations](https://github.com/ramosdalrymple-afk/mhgu-save-editor/blob/v0.1.0-alpha.2/docs/KNOWN_ISSUES.md)
before editing equipment. This release focuses on the interface and branding;
gameplay behavior still requires in-game validation.

### Verification

Built from committed source with private game assets excluded. The release
checks cover automated regression tests, all five pages at three window sizes,
portable startup, and installer installation/uninstallation.
