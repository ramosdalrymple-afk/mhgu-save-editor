## MHGU Save Editor — Early Access

First Windows x64 prerelease for Monster Hunter Generations Ultimate save editing.
This is an experimental build with known equipment limitations; in-game validation
is still required.

### Downloads

- **Installer:** `MHGU-Save-Editor-0.1.0-alpha.1-win-x64-Setup.exe` — installs for the
  current user, with a Start menu shortcut and an optional desktop shortcut.
- **Portable:** `MHGU-Save-Editor-0.1.0-alpha.1-win-x64-Portable.zip` — extract the
  complete archive and run `MhguSave.App.exe`.
- **Checksums:** `SHA256SUMS.txt`.

Both packages include the .NET runtime. No separate .NET installation is required.
These are unsigned Windows builds. Linux and macOS binaries are not provided.

### Included

- Sidebar navigation, searchable inventories, and separate equipment editing,
  creation, and decoration panels.
- Hunter profile, item box/pouch editing, quest flags, and supported unlock actions.
- Corrected Rathalos S and other armor name-to-save-ID mappings.
- Automatic timestamped backups, paired save writing, external-change detection,
  and a write guard while recognized emulators are running.
- Community armor category symbols. Optional original game artwork and extracted
  sprites are excluded, along with saves, keys, and game archives.

### Known equipment issues

- **Avoid Palico gear creation:** the current form writes to the hunter box instead
  of the separate Palico equipment box.
- **Do not clear worn or registered equipment:** equipped/My Set references are
  not updated, and reusing the slot can redirect a loadout to a different piece.
- Jewel capacity assumes three sockets for non-talismans rather than the actual
  piece and upgrade level.
- Talisman rarity and charm origin are not synchronized automatically.

Read [all known issues](https://github.com/ramosdalrymple-afk/mhgu-save-editor/blob/v0.1.0-alpha.1/docs/KNOWN_ISSUES.md).
Use a separate save-folder copy for early-access testing and close the emulator
before saving. Please include reproduction steps when reporting bugs, and omit
private keys and game files.

### Validation

Built from committed source with no local game assets. Automated regression checks,
portable startup, and installer installation/uninstallation were checked before
publishing. Gameplay behavior has not been fully validated in game.
