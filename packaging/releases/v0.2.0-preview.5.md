This Early Access update expands the Windows editor with three new workspaces and improves editing, layout, and save protection across the app.

### What's new

- **Loadouts and sets.** Edit 40 hunter sets and 24 Palico sets. Choose gear, hunting styles, Hunter Arts, and armor pigment.
- **Palico board.** Edit existing companions and hireable Palicoes, assign hunting roles, and browse their equipment in a separate box.
- **Monster journal.** Edit slain and captured counts across 137 monster records and inspect recorded sizes.
- **Inventory tools.** Sort or merge item stacks and import or export the item box as CSV.
- **Profile and collections.** Edit appearance and play time, and toggle individual awards, Hunter Arts, and obtained items.
- **Desktop layout.** Clearer form groups, compact number controls, and Add and Apply actions that stay within reach. Search, ID, quantity, and Add appear together in the inventory editor.
- **Save protection.** Changes to either save file since opening trigger a conflict check. Invalid numeric edits still block Save after switching tabs. Equipment references protect worn and registered gear.

### Windows downloads

| File | Use |
| --- | --- |
| `MHGU-Save-Editor-0.2.0-preview.5-win-x64-Setup.exe` | Per-user installer with a Start menu shortcut. |
| `MHGU-Save-Editor-0.2.0-preview.5-win-x64-Portable.zip` | Extract the full ZIP and open `MhguSave.App.exe`. |
| `SHA256SUMS.txt` | Check the integrity of both downloads. |

Both downloads include the runtime for Windows 10 or later on x64. The application and installer are unsigned. Public packages use the bundled icons and catalogs. Optional local game tables enable native rarity labels and socket validation for hunter weapons and armor in local builds.

Use a separate save copy and close the game or emulator before writing changes. See the [known limitations](https://github.com/ramosdalrymple-afk/mhgu-save-editor/blob/v0.2.0-preview.5/docs/KNOWN_ISSUES.md) for equipment and in-game verification details.
